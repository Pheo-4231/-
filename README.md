# 전주대 대동제 및 해커톤 통합운영 데이터 로그 분석

## 1. 프로젝트 개요

정규 표현식(Regular Expression)을 활용하여 전주대 대동제 및 해커톤 통합운영 데이터 로그에서 필요한 정보를 자동으로 추출하고 분석하는 프로젝트입니다.

로그 데이터에서 이메일, 전화번호, 학번 및 학과, GitHub 저장소 주소, 쿠폰 번호와 부스별 매출 정보를 정규 표현식으로 추출합니다.
(과제에서 제시한 추출 조건에 따라 학번 추출 과정에서 정규표현식을 사용하여 202로 시작하는 9자리 학번만 추출하도록 조건을 설정했는데 로그 데이터에 포함된 학번 20261122는 8자리이므로 지정한 추출 조건에 적합하지 않아서 어쩔 수 없이 결과에서 제외했습니다.)

## 2. 사용한 코드

- Python
- 정규 표현식 (Regular Expression)
- Python `re` 모듈
- 파일 입출력

## 3. 분석 대상

`07-02. 전주대 대동제 및 해커톤 통합운영 데이터 로그.txt`

## 4. 주요 기능

### 이메일 추출
로그에 포함된 유효한 이메일 주소를 추출합니다.

### 전화번호 추출
`010`으로 시작하고 `-`, `.`, 공백으로 구분된 휴대전화 번호를 추출합니다.

### 학번 및 학과 추출
`[학번 / 학과]` 형식에서 202로 시작하는 9자리 학번과 학과를 추출합니다.

### GitHub 저장소 추출
GitHub 저장소 주소를 추출하고 GitLab 주소는 제외합니다.

### 쿠폰 번호 추출
`FEST-2026-XXXX` 형식의 2026년 쿠폰 번호를 추출합니다.

### 매출 분석
각 부스의 `매출:` 뒤에 있는 총 매출 금액만 추출하여 전체 매출을 계산합니다.

## 5. 실행 방법

1. Python이 설치되어 있는지 확인합니다.
2. `main.py`와 로그 파일을 같은 폴더에 넣습니다.
3. 터미널에서 다음 명령어를 실행합니다.

```bash
python main.py
```
